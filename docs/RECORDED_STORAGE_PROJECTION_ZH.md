# 普通目标显式缓存证据的存储投影

**[English](RECORDED_STORAGE_PROJECTION.md) | 简体中文**

## 范围

`project_storage_references(RecordedTargetResult, path_key, limits)` 和
`RecordedStaticTargetResult` 重载，纯粹消费已捕获的最终编译波次，返回拥有数据的结果。
EXE/DLL、静态库保留源顺序和原有 LINK/LIB 终端投影。默认 `run/inspect/CLI`、
admission-stop、代际模型、持久化、写者协调及 `clean/prune` 不变；这不是 v5.7.0 发布。

## 选定事实与对应校验

结果拥有 `references`，并为每个编译阶段保存一个 `CompileStorageContext`。
阶段采用自己的工作目录、编译配置、完成状态及准确的 `saved/reused/save_failed` 结果。
缓存依赖和头搜索命名空间根为输入引用；object 为声明输出，依赖 JSON 与 cache 路径为元数据引用。
使用的 PCH 仍是输入；额外 object 仍是上游终端输入，不能伪造成本地生产者。
路径原拼写、顺序和重复引用保留；非关键的未解析输入继续作为字面引用交给原关联层报告。

检查上下文的编译器身份与实际缓存的编译器身份分别复制，差异明确标记，不统一成虚假的实际工具链。
签名只是原样复制的不透明值；投影不重算配方、不读文件，也不能认证调用方提供的结构。
编译警告和保存错误的代码、文件、偏移与消息由返回值拥有，不复制完整进程输出或工具链环境。
`save_failed` 表示尝试值，不表示持久化成功；复用不会产生新的执行代际；标签仍只是调用者注释。

源数量或顺序、source/object/元数据路径、完整结构化选项（包括有序参数和提供者）、缓存输出形状、
完成/警告/保存状态、终端对象顺序不一致，均以类型化问题和可选源下标拒绝整个结果。
普通目标重载不重新解释 module/HU/PCH 创建者记录。这是选定字段的一致性检查，
不是新的编译器验证器，也不证明不透明签名与配方相符。

## 路径与资源边界

关键源/输出/元数据路径必须为绝对路径，或能够从本阶段记录的绝对工作目录解析。
空路径、NUL、父目录跳转或缺少自身上下文的关键路径被拒绝，不借用 LINK、进程或目录扫描的工作目录。
调用者提供既有平台的纯词法路径 key；重复源、输出/元数据冲突、受保护输入别名、
本地 object 在终端的上下文冲突均拒绝。key 异常原样传播；词法一致不是物理身份或当前内容证明。

默认最多 **100000** 个源、**1000000** 个选定项目、**64 * 1024 * 1024 个本机字符代码单元**。
调用者只能调低，不能突破默认上限。复制和批量分配前按剩余额度安全扣减，超限返回错误，
不截断、不发布部分成功。限制覆盖选定字段处理及输出，不涵盖调用方已分配的输入、
分配器管理开销或受信 key 回调执行时间；不构成完整内存/耗时资格。
所有物理身份、当前内容、完整清单、删除权限仍为 false；旧 record-only 重载的未知语义不变。

## 验证与剩余门槛

便携 C++ 合约覆盖类型化拒绝、EXE/static 输出、独立拥有值、混合工具链/复用、保存失败、
相对路径上下文、别名、终端对应及低限额。既有真实 EXE/DLL/static 生命周期仅消费同次返回值，
不额外调用 cl/link/lib 或写入新的证据文件。历史源码测试通过完整新文件指纹与精确逆变换核对旧文件，
不丢弃旧摘要或断言。Python 合约不能代替 Windows Native/Release 执行。
显式复制、分配、峰值/驻留内存及默认路径生成代码/性能变化仍需独立审阅，不批准默认或高频采用。
