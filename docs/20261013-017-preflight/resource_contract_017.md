# 017 元数据预检的范围和资源契约

这是**前置校验阶段**契约，不是原图像选择或正式反汇编执行的准入。
范围只包含固定元数据、两个旧宿主文件的只读检查，以及纯值/临时文件测试。
后续 103 B 选择、独立准备、GNU 进程和完整工具依赖必须另有审阅后的资源契约。

## 固定输入与关联

五个公开输入角色的精确长度和 SHA256 写在 `bcrypt_preflight_017.PINS` 中。
输入总量 **318,238 B**，不是整个历史包，也不是原 Windows 图像。

| 角色 | 原件 | B |
|---|---|---:|
| index | 013 `offline-013/report.json` | 271920 |
| caller | 016 `offline-016/report.json` | 3583 |
| runtime | 016 `runtime-review-admission-016.json` | 17743 |
| closure | 016 `final-closure-admission-016.json` | 16812 |
| proposal | 016 `next-target-candidate-017.json` | 8180 |

必须拒绝缺少/多出角色、长度或哈希不符，然后才允许 JSON 解码。
拒绝重复键、NaN/Infinity、指数溢出的非有限数、非对象根和不一致字段。
类型严格比较，不能把 false 当成退出码 0，也不能把 true 当成 1。

此 API 接收可信 Python 调用方已持有的 bytes，不提供文件读取器、网络下载器、
任意图像参数或子进程入口。不声称限制调用方在调用前已经分配的内存。
五份身份固定后，解码内容也固定；本函数不是面向任意敌对 JSON 的通用解析沙箱。
JSON 分配、解释器基线和宿主 RSS 不宣称硬上限，未沿用 016 的进程内存证明。

## 新目标几何，尚未选取新目标字节

- 来源：已验收 016 的 CALL RVA `0xDB84`，5 B，原字节 `e8f3350000`。
- rel32 = +13811；`0xDB89 + 13811 = 0x1117C`。
- 唯一 runtime302：文件/RVA `[0x1117C,0x111E3)`，103 B，section0 `.text`。
- preferred VMA = RVA + `0x180000000`；不是实际进程 ASLR 地址。
- `.pdata` 行：文件 `0x22E28`，12 B；预期原字节 `7c110100e31101004cdd0100`。
- unwind：文件/RVA `0x1DD4C`，8 B；预期原字节 `0104010004420000`。
- unwind version1 / flags0 / depth1；没有 chain、handler 或保留帧寄存器。

以上是与固定元数据的关联核对。返回的 `required_future_snapshot_checks` 指明
未来准备必须从快照分别复核的三个原件位置，**不是本轮已经读过那些文件字节**。
目标 SHA256 保持 null；邻近 `0x111EC` 不作为替代范围。

重建与哈希旧 016 的 18 个已记录 raw_hex 只是核对已有 83 B 记录的一致性，
不重新运行解码器，也不授予任何新区域的读取权限。

## 宿主检查与停止行为

仅检查 `bcrypt_environment_017.OLD_PINS` 中的两个固定路径。
每个普通文件上限 64 MiB，分块 65,536 B，额外至多一个 1 B EOF 检测请求。
Linux 使用 O_NOFOLLOW/O_NONBLOCK/O_CLOEXEC；拒绝符号链接叶、FIFO、目录、
超限/短读/增长/前后身份变化。打开句柄关闭错误不升级为匹配或执行成功。

上界是两个文件最多 134,217,728 个内容字节，外加至多两个 EOF 请求。
这不是 OS 同步 I/O 的硬返回时间保证。父目录属于可信宿主边界，
没有宣称祖先目录全部 pin 住，也没有宣称随后实际装载到同一映像。

本次一个 Python 路径缺失，另一个工具内容身份不匹配。
返回 `BLOCKED_ENVIRONMENT_CHANGED`，不修补旧清单，不安装/下载工具，
不执行 `--version`、`--help` 或任何反汇编命令。
即便两个旧文件完全匹配，也不能省略新解释器/依赖/loader/alias/absence 与调用边界审阅。
