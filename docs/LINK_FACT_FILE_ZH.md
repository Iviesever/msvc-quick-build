# 显式历史快照文件

[English](LINK_FACT_FILE.md) · [纯编解码](LINK_FACT_SNAPSHOT_ZH.md)

## 范围与接口

`mqb/platform/windows/LinkFactSnapshotFile.hpp` 提供非默认接口：
`create_link_fact_snapshot_file(path, snapshot)` 和 `read_link_fact_snapshot_file(path)`。
只读写一条严格 JSONv1 历史快照，不接入默认 build/CLI、缓存或观察器。
四项授权始终 false；格式正确不认证来源，更不证明历史产物现在存在、内容不变或可删。

## 仅新建协议

先编码与验证，再访问文件系统。父目录必须已经存在。使用 CREATE_NEW 和不共享的
新文件句柄，不采用“exists 检查后截断打开”；不覆盖、不追加、不替换、不自动重试。
有限分块允许成功短写，零进展或原生错误立即停止。成功要求所有字节写完、
FlushFileBuffers 和 CloseHandle 均成功；已知传输字节与原生错误分别保留。

创建后失败可能留下部分或完整的新文件，故意保留，不自动删掉、改名、覆盖或在重试时
采用旧记录。错误包含是否已创建、已知传输字节和附加关闭错误。写入字节不是持久化
证明；之后读到合法 JSON 也不能证明此前写者收到了成功回执。这不是崩溃原子发布、
提交标记、事务日志或持久写者协调。

## 有界读取与路径

只接受普通绝对盘符路径、本地 volume-GUID NTFS；归一化前检查语法及 UTF-16，
拒绝设备、UNC、ADS、父路径跳转、保留别名及长度/深度超限。复用原私有路径和
read-pin 原语，持有根目录与逐级祖先句柄到调用结束，拒绝重解析点与错误文件类型。

读取使用同一句柄和数据/属性权限、FILE_SHARE_READ，不降级为只读属性句柄。
先获取尺寸并限制 1 MiB，再分块读到声明长度，额外探测 EOF、重新核对长度，关闭后
交给原严格编解码器。短文件、增长、超限、非法 JSON/UTF8/schema 及原生读取错误均
拒绝，不回退缓存或伪造空快照。已有普通写/删除句柄冲突时拒绝。

句柄只在本次调用内持有，不跨操作协调；不承诺抵抗特权驱动器映射、内核写入、所有
映射文件场景或宿主丢失；同尺寸恶意变更不具有内容认证。字节/深度/进度限制不等于
同步内核 I/O 超时。祖先句柄 RAII 与分配异常保持既有私有原语行为；bad_alloc 可传播，
已创建文件仍保留。

## 测试、证据与发布限制

新增两个原生程序：生产 transfer 模板的短写/读取/EOF/flush/close 合成故障测试，
以及 Windows 真实新建、拒绝覆盖、读回、非法路径/UTF16、大小限制、硬链接、写者
冲突、两个并发创建者与真实 junction 拒绝。Windows 过程与文件保存在
`storage-evidence/snapshot-file/`，由未修改的原生 CI 保留；合成传输不是原生验收。
原91测试程序和codec/观察器不改，驱动总数93、含main生产TU94；无新workflow或性能入口。

未发布5.7，未开启默认快照采集、删除、代际退休、全项目写者协调、Rium资格，也没有
解除旧性能失败。已消耗研究不重跑取更好样本。
