# 显式目标代际与保留声明

**简体中文 | [English](ARTIFACT_GENERATIONS.md)**

## 范围与使用

`model_artifact_generations` 接收已完成的普通、静态 LIB 或模块目标的 typed 记录及显式保留请求，返回拥有副本的历史关联、冲突和选择结果。不构建、不扫描、不读时钟、不做文件 IO、不更新注册表、不删除、迁移或自动 GC。没有默认 build/CLI 接入，也没有持久化格式。

输入包含唯一的历史 `source_id`、明确 project/target 键、可选代际键、原编译器上下文（或者未知）、原目标记录及可选的单条链接主输出快照。调用者注释单独保留。键是区分大小写的不透明声明，不从路径、标签或时间戳猜出，也不是密码学或可信写者身份。

## 身份与代际关系

模型保留选中的有效 compiler/link/LIB 字段、工具链路径/版本/不透明 stamp、终端签名、有序选项、声明路径和模块编译/导入证据。长度分帧仅作字段精确比较，不另创缓存签名；不排序或消除重复选项。旧目标记录没有编译器上下文，缺失就保留 `missing_compiler`，不反推或冒充已捕获。

执行结果加明确代际键只成为**未经验证的代际声明**，不证明真实生产者。复用必须明确引用同批次、相同 project/target、唯一执行声明及一致的选中配方证据。复用不创建新来源、不沿纯复用链猜出处、不按最新签名匹配。终端声称复用而某阶段实际执行，记为 `mixed_reuse`。来源或代际重复、完成状态不一致、来源缺失、配方冲突和快照不符都显式保留；不静默合并，不以输入顺序推导时间或退休。

`recipe_evidence` 只是内存诊断内容，不是稳定序列化或完整内容/环境身份；它不包含编译输入内容状态、ProcessSpec 环境和完整 P1689 图。因此不证明动态等价、不全面验证任意伪造记录，也不认证调用者提供的工具链上下文。可选快照沿用原严格编解码器并与终端链接字段核对；不能补齐缺失目标身份，更不能变成完整产物库存。

## 路径冲突与显式保留

角色投影和词法路径关联复用原 `project_storage_references` 与 `associate_artifact_storage`。调用者提供平台已有的纯 `StoragePathKey` 和绝对词法根目录。传入的是空观察清单，不扫描文件。相对路径必须有所在阶段自己的原 cwd，不能用终端 link 的 cwd、清单根目录或当前进程 cwd 代替；父目录穿越保持未解析。路径键回调必须稳定、仅词法且无副作用；其异常传播。

结果保留来源/阶段/路径索引及输入、声明输出和元数据引用角色。共享 object/PCH/IFC、同输出的多个执行代际、不同目标/配方及未确认成员都显示出来。这是潜在共享或覆盖冲突，不是当前文件观察；不同词法路径可能互为物理别名，本层不发现此关系，不将历史文件 ID 提升成可信生产者身份。

每个显式保留请求都保留，包括重复、缺失和歧义。`selected` 仅说明请求指向唯一历史声明，并包括可关联的复用记录及路径引用；不保证所有文件存在或完整覆盖。即使声明被选择，未解析路径仍可见。未选中、缺失和冲突记录都**不代表已经退休**；本 API 没有删除清单或可回收字节总量。

## 限制与测试

最多 256 输入记录、256 保留请求、4096 投影阶段、65536 路径/条目，以及 8 MiB 累计选中文字预算。显式键非法、超预算、路径键或根目录不合法会拒绝整个请求，不截断或伪造部分成功。路径转换、内存分配和回调异常可以传播，调用者输入不被修改；结果副本在输入更改或销毁后仍保留来源、标签、支持的快照及引用。

`artifact_generation_model_tests.cpp` 覆盖普通/静态/模块记录、显式复用及缺失来源、既有选项类别与顺序变化、重复声明、跨配置同输出、共享 object/PCH/IFC、仅 IFC 生产者、非法/不匹配快照、缺失编译器、相对路径、容量和回调失败。这些是纯模型测试，不是 Windows 文件系统、跨进程写者或性能实测。现有 CI 使用只增加清单数量的原生驱动执行它；Python 边界控制保留原测试、配方及 IO 权限约束。

## 权限及后续边界

生产者身份、当前内容、完整产物库存与删除许可四项权限继续为 **false**。记录缺席、缓存未命中、代际名或保留选择都不授予删除权限。本切片不登记可信写者、不分配全局唯一代际、不做跨进程记录合并、不提交或恢复持久化状态，也不执行清理前文件身份复核；这些机制和 Rium 验收仍为后续必做。原性能数据及不利样本保持不变，非默认模型不证明零开销，也不批准发布 v5.7.0。

## 普通目标完整记录的显式入口

`model_recorded_artifact_generations` 同步借用已完成的
`RecordedTargetResult` 或 `RecordedStaticTargetResult`。调用期间，原返回值必须
保持存活且不变。返回的 `model` 和 `compiles[record_index][source_index]` 拥有所选
历史数据，不借用进程环境、输出缓冲区、计时器或缓存向量。

该显式入口复用严格的完整记录投影，以及旧入口的**同一套**代际、保留和词法关联实现。
每个源文件捕获的检查工具链、缓存工具链、签名、请求选项、自身工作目录、依赖和有序
包含根均参与所选配方比较。不同工具链分别保留，不强行归一为一个全局 compiler；
身份字段缺失仍记为 `missing_compiler`。缓存结果、`force_rebuild`、保存错误及警告
被保留，但不作为配方身份。目标声称整体复用却包含已执行源仍标为 `mixed_reuse`；
已执行目标内部的部分源复用保持可见，不替这些源编造独立代际。

仍须显式提供来源、项目、目标及代际声明。孤立的复用记录不能创造来源。真实角色冲突
由严格投影拒绝，原错误类型、源下标和消息与批内记录下标一并返回。非法声明或超限使
整批失败；代际关系或快照矛盾继续作为模型问题保留，不发布部分成功。

整批所选输入先按已有模型与投影的交集限额检查，再复制拥有型结果或调用词法路径键。
所选文本及结构遍历有界；路径转换和现有有界快照编码器仍可能使用临时分配。这不是
总分配量、峰值或驻留内存保证。不读取文件系统，不重算签名。旧入口及模块路径继续
保留原有的未知上下文语义，原模型检查不删除。

原生检查在原始证据保全之后消费已有 EXE／DLL／静态库调用的返回值，不增加编译、
链接或观察调用。新增测试侧模型复制与日志输出不等于零成本。该入口不接入默认 CLI、
持久化、writer、clean/prune 或发布流程。
