# 非 MQB 启动器预检

**[English](EXTERNAL_NOOP_PREFLIGHT.md) | 简体中文**

## 目的

本预检独立验证[保留程序诊断采集器](EXTERNAL_NOOP_BOUNDARY_ZH.md)的真实启动函数。
不执行 MQB，不下载或重建原 A/B，不生成新的性能成绩，不解除 #207 原性能 HOLD。
通过预检也不等于分配原40次研究。

预检只从原 PowerShell 文件的顶层 AST 提取五个白名单函数，包括两个原启动函数。
不执行原脚本入口，也不加载 `Invoke-RegisteredStudy`。原启动器的规范 LF 文本
具有固定 SHA；实际检出的原字节（含 Windows CRLF 表示）完整复制、单独计算摘要。
启动器代码改变时必须明确审阅和更新固定摘要，不能悄悄换一个启动器来验收。

## 固定预算

|启动尝试|方式|预期行为|
|---|---|---|
|1、2|Legacy、Process|回传真实参数、cwd、解释器与源码身份|
|3、4|Legacy、Process|双流并发压力，每个流262,144字节|
|5、6|Legacy、Process|原样保留退出码37|
|7、8|Legacy、Process|不存在的可执行路径，无辅助进程标记或虚构退出码|
|9|Process|真实180秒根等待失败，保留输出和有限清理状态|

最多9次启动函数调用、7个真实辅助子进程。辅助程序只使用已安装的 Python 和标准库，
不启动后代。参数包含空字符串、空格、引号、尾部反斜杠和 Unicode。每个辅助进程
先独占创建自己的 PID/cwd/argv/源码标记。压力模式使用两个线程，每个流256行、
每行1,024字节。各流内顺序固定，合流交错顺序不固定；Legacy 保存的是行而非原始字节。

超时辅助程序先输出两条就绪记录，再睡眠240秒。必须由未经修改的启动器180秒等待
触发失败，保留原输出，并在原尽力清理后报告根进程退出。自然退出、缩短等待、缺失
标记或声称后代全部退出都不通过。本预检没有覆盖独立的10秒管道排空超时、任意API
故障、后代持有继承句柄或恶意IO。

原40次 MQB 研究预算不动。每个新候选的首次正常事件执行一次固定预检；合并后的自然
main检查另行记账。不重跑同一提交择优、不补齐、不恢复执行。两平台合成契约测试不
启动辅助子进程。驱动还最多调用11次只读/写证据的Python检查器（计划、9次判定、
最终审计），它们不调用启动函数。仓库普通原生/自举流程维持各自既有预算。

## 证据与失败

输出根必须全新。先快照五份源码、记录解释器身份、计划和宿主设置，再逐次写入启动
记录。原始返回观察及宿主cwd在语义判定之前落盘。预定非零退出、缺失路径和超时
仍以原始失败保存，测试预期正确不改变原观察。首次非预期错误停止剩余槽位并保留
stopped状态，不删除异常项、不覆写报告、不修好夹具重试或补齐样本。

最终审计核对完整53份调用文件，包括模式专有输出流和子进程标记；重算每份保存判定，
严格校验完成计数和零研究标志。采集时重算解释器与源码摘要。迁移附件的离线审计
核对源码字节及保留的解释器前后身份，不冒称能读取旧runner上未下载的解释器字节。
解释器完整安装及标准库没有做封闭快照。日志闭合不是“无未记录进程”或并发原子性证明。

QPC顺序和退出后的根FILETIME/CPU值分别检查，不跨时钟相减、不冒充后代CPU。
Process成功及非零退出的根PID必须对应辅助进程标记；Legacy根计时保持null。
PowerShell位置及宿主环境cwd必须恢复。不计算性能门槛、不扣除观察成本、不自动
判断根因，也不增加产物清理权限。

## CI与复核

`External no-op helper preflight`先在Linux/Windows分别运行21项合成测试，再执行
固定9次Windows预检。独立job时限10分钟，也覆盖同步Legacy调用。`always()`上传
包含失败的原始证据；作业被终止或附件服务失败仍可能阻止上传，此时是缺证据而非通过。
没有dispatch触发、A/B下载、重试或`continue-on-error`。

在审阅本固定辅助程序分配后执行：

```powershell
./tests/native/preflight_external_noop_boundary.ps1 -OutputRoot NEW_DIRECTORY
```

迁移后的原始附件可以不启动任何被测进程、只做离线审计：

```powershell
python tests/native/external_noop_preflight.py audit EXTRACTED_EVIDENCE --output NEW_AUDIT.json
```

只有在原runner上才加`--live-interpreter`重算当前解释器。退出0仅表示本预检符合计划，
退出2表示非法、不完整或拒绝覆写；都不分配原研究。下一步还须单独冻结审阅真实研究
执行器、源码/输入摘要、job时限与失败上传。

一手API依据见[英文文档](EXTERNAL_NOOP_PREFLIGHT.md#primary-api-references)：
GetProcessTimes的退出值只能在退出后使用，重定向管道需并发读取防止阻塞，根进程
WaitForExit/HasExited不证明全部后代退出。
